One sentence pitching a ridiculous invention that fixes a tiny everyday annoyance — a [make.fun](https://make.fun) bounty entry by [@dizellacapital](https://make.fun/r/qxacafna).

## The pitch

> A printer that refuses to print until you compliment it, then jams in silent protest the moment you raise your voice.

117 characters. Everyone has lived printer rage: it jams exactly when the document is urgent. This printer's fix is the joke itself — it demands flattery before it prints, and answers shouting with a deliberate, silent jam. Silly, yet weirdly plausible.

## Run it

```sh
python3 main.py  # writes entry.txt to $MAKEFUN_OUTPUT_DIR (fallback /output)
```

`main.py` (stdlib only) validates the pitch is one sentence of 1–220 characters, writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), then reads it back to verify the written bytes match.
